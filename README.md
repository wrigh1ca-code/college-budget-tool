# Budget Builder

A budget planner for college students. It's a single page with no build step and no server. Open `index.html` in a browser, or host it with GitHub Pages.

## What it does

- **Tuition goal:** tracks progress toward the next tuition payment and sets aside more in summer, when you earn more.
- **School-year and summer budgets:** separate income and spending for each season, plus a full-year total.
- **Apartment fit:** checks how a specific apartment fits the budget, including the highest rent share you can afford.
- **Move-in costs:** lists one-time moving costs, with a checkbox to mark each one as paid by you or covered by family.
- **Net worth:** tallies what you own and owe in one place.
- **YNAB setup:** a list of categories with monthly targets, ready to copy into YNAB.

## Privacy

Everything you enter is saved in your own browser's local storage. Nothing is sent to a server, and nothing is stored in this repository.

## Hosting

Settings → Pages → Deploy from a branch → `main` / `(root)`.
